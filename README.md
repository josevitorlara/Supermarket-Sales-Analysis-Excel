Projeto de análise de dados com Excel: limpeza (ETL), Tabelas Dinâmicas e Dashboard executivo para tomada de decisão.
# 🛒 Análise de Performance de Vendas - Supermarket Sales

![Capa do Projeto](./assets/Capa de Projeto.png)

## 📌 Visão Geral
Este projeto consiste na análise de faturamento de uma rede de supermercados com filiais em três cidades diferentes (Mandalay, Naypyitaw e Yangon). O objetivo foi transformar dados brutos em um dashboard executivo para facilitar a tomada de decisão da gerência.

## 🛠️ Ferramentas e Técnicas Utilizadas
* **Microsoft Excel:** Utilizado para todo o processo de ETL e visualização.
* **Limpeza de Dados:** Tratamento de formatos de data (conversão MDA para DMA), ajuste de pontuação decimal e verificação de duplicatas.
* **Manipulação de Dados:** Uso de tabelas dinâmicas para sumarização de faturamento por categoria, cidade e gênero.
* **Dashboard Interativo:** Criação de visualizações de tendência, rankings e segmentação de dados (filtros interativos).

## 📊 Insights Extraídos
* **Principais Categorias:** A categoria de **Electronic accessories** lidera o faturamento, seguida de perto por **Sports and travel**.
* **Tendência Temporal:** O faturamento demonstrou estabilidade no primeiro trimestre de 2019, com uma leve retração no mês de fevereiro.
* **Perfil do Consumidor:** Houve um equilíbrio entre os gêneros, com uma leve predominância do público feminino no faturamento total.
* **Performance Regional:** A filial de **Yangon** apresentou o maior volume financeiro no período analisado.

## 📂 Como visualizar o projeto
1. Faça o download do arquivo `Dashboard_Vendas_Supermarket_Sales.xlsx`.
2. Abra o arquivo no Excel.
3. Utilize os botões de segmentação (se configurados) para filtrar as análises por cidade ou tipo de cliente.
